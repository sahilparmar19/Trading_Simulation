The `Pharmacy` class represents the pharmacy and manages the medicines. It has an instance variable `medicines` of type `LinkedList<Medicine>` to store the medicines in the pharmacy inventory as given in sample list as well as if new one added by user.

The class has a constructor that initializes the `medicines` list.

   - `displayMedicines` method: There should be method to display the medicines in the pharmacy.

   - `sellMedicine` method: This method allows selling a medicine from the pharmacy to respective customers thread by maintaining data consistancy.
