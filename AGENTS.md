# Trading Simulator AI Development Rules

## Workflow
Before making any code changes:

1. Read and audit all relevant files.
2. Explain the root cause of the issue.
3. Present a clear implementation plan.
4. Wait for explicit approval.
5. Implement only after approval.
6. Make the smallest possible change.
7. Preserve all existing functionality.
8. Do not introduce unnecessary dependencies.
9. Verify the code after implementation.

## Coding Standards

- Follow Java best practices.
- Maintain thread safety.
- Preserve JDBC compatibility.
- Keep methods clean and readable.
- Avoid duplicate code.
- Never break existing APIs.

## Review

Every response must include:

- Files inspected
- Findings
- Planned changes
- Risks
- Verification steps

Never skip the audit phase.
